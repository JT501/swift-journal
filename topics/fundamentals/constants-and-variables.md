---
title: Constants and Variables
---

Use `let` for a value you won’t reassign and `var` for a value you need to change. Start with `let` and switch to `var` when you need reassignment.

## Try it

Declare the name of a lesson with `let` and the number of completed exercises with `var`. Increment the count, then try reassigning the lesson name and read the compiler error.
